# c1-hochschule-lexicon — agent instructions

Source release of the German–Turkish lexicon shipped in the C1 Hochschule
Hazırlık app (`telc-c1-hochschule-app`). It exists so the GPL FreeDict material
can be had in source form by anyone who receives the app. `README.md` lists the
sources and their licences; keep that table true.

## Hard rules

- `assets/data/lexicon/*.json`, `assets/data/lexiconMeta.json` and
  `src/data/lexiconShards.ts` are generated by `scripts/build-lexicon.mjs`.
  Never hand-edit them; change the sources or the script and rebuild.
- Licence terms are part of the product: GPL for the FreeDict-derived parts,
  CC BY-SA / GFDL attribution for the Wiktionary-derived parts. A change that
  drops an attribution or mixes licences is blocked.
- The app repo is the consumer: a shard-format change here must be mirrored
  there in the same task, or the task is not done.
- Node.js 18+ only, no other dependencies.

## Commands

```bash
node scripts/build-lexicon.mjs           # regenerate the outputs
node scripts/build-lexicon.mjs --check   # confirm committed outputs match the sources
```

## Definition of Done (extends the global default)

- Gates: `node scripts/build-lexicon.mjs --check` green.
- Visual/device proof: n/a.
- Merge: PR against `main`, `gh pr merge --squash --delete-branch`.
- Deploy: none (published source repo).
- Live check: n/a.
- User-only steps (report, do not attempt): licence decisions, adding a new
  upstream source.

## Agent loop

- The reviewer re-runs the build and checks `git status` is clean afterwards.
- Do not read the shard JSON files or the TSV/JSONL sources whole; grep them.
